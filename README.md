# BOM 物料库匹配工具 · 开源版

面向电子制造 BOM 整理的本地桌面工具：导入初始 BOM 与物料库，提取规格参数，推荐匹配项，人工核对后导出 Excel。

作者：**桀桀** · 联系作者：微信 **JJ-Linnnnn**

本版本不包含注册、激活、机器绑定、到期限制或注册机。无需联网，不上传 BOM。它与原版使用独立配置目录，可单独运行。

## 功能

- 导入 XLSX、XLSM、XLS、CSV，识别常见中英文列名。
- 规格归一化：电容、电阻、电感及保险丝、LED、二极管、MOS、IC、连接器等类别；识别常见数值、单位、封装、引脚数与尺寸写法。
- 多参数匹配与冲突检查，支持搜索候选物料、人工套用和逐行确认。
- 物料库规格分析缓存，可选择启动时自动加载上次物料库；文件不存在时跳过。
- 只读 BOM 预览；结果表列标题和顺序可定制，点击完成后统一应用。
- 原生“另存为”窗口选择 Excel 保存路径和文件名。

## 快速开始（Windows）

建议 Windows 10/11、Python 3.12（安装时包含 Tcl/Tk）。无需独立显卡。以下命令在仓库根目录的 PowerShell 中执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe ad_bom_matcher.py
```

发布包中的 EXE 可直接运行，不需要安装 Python。其他系统未进行完整界面验收；部分文件对话框逻辑面向 Windows。

## 使用步骤

1. 在“匹配”页导入初始 BOM，再导入物料库。初始表建议包含规格/型号、数量、位号、封装；物料库建议包含物料编码、物料名称、规格、单位。
2. 点击“自动匹配”。检查物料编码、规格、封装、耐压、精度及数量。
3. 对有疑问的行，先选择初始 BOM 行，在顶部搜索规格，再双击候选物料套用。结果表可人工修改，核对后勾选确认。
4. 在“预览”页只读检查结果。在“设置与帮助 → 导出规格”可修改结果表显示列名、拖动排序，完成后点击应用。
5. 点击“导出 Excel”，选择位置与文件名，保存后检查生成文件。

颜色：浅绿为自动匹配，红色为需核对的差异，深绿为已确认，浅蓝为当前选中。自动匹配不等于工程上已批准替代。

## 匹配规则与边界

- 未写耐压的电容默认按 **50V** 参与匹配；未写精度的电阻默认按 **1%** 参与匹配。请确认这些默认值符合自己的业务。
- 标准化单位与别名后，结合类别、型号、数值、封装及其他参数比较；明确的参数冲突会影响或阻止匹配。
- 缺少型号/关键参数、供应商自定义简称、特殊封装以及物料库根本不存在的器件，仍可能需要人工处理。不能保证任意 BOM 全自动正确匹配。
- 不应仅凭匹配分数采购或替换器件；尤其须核对引脚定义、额定值、极性和厂家数据手册。
- **当前显示列定制不改变 Excel 导出结构**。导出固定九列：层级、工序、物料编码、物料名称、规格、用量、单位、位号、点数。界面“备注”列目前显示匹配分数，不导出。预览用于核对数据，不是最终 Excel 排版预览。

## 本地数据

Windows 配置和规格缓存位于 `%LOCALAPPDATA%\BOMMaterialMatcherOpenSource`（依次回退到 APPDATA、用户主目录）。包含上次物料库路径及分析缓存，仅保存在本机。请不要把该目录、真实公司 BOM 或内部物料库提交到 GitHub。程序不会修改导入文件；请另存导出结果，避免覆盖重要文件。

## 测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试包括封装归一化、多器件匹配和只读预览。GUI 测试需要可用桌面及 Tk，不能直接在无显示服务的 Linux CI 环境运行。

## 打包 EXE

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe build.py
```

输出：`dist/BOM物料库匹配工具_开源版.exe`。图标由项目自己的绘图代码生成，不使用 Apple 商标图标。首次启动单文件 EXE 需要解压运行资源，可能略慢。

## 项目结构

```text
ad_bom_matcher.py       界面、表格读写、规格分析与匹配

requirements.txt        运行依赖
requirements-build.txt  打包依赖
tests/                  回归测试（合成数据，无真实物料库）

```
